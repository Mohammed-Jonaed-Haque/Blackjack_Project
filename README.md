## 🎮 Blackjack Game (Python)

# Overview

This project is a **console-based Blackjack game built in Python**, where a player competes against a computer dealer using standard Blackjack rules.
The goal is to get as close to 21 without exceeding it while beating the dealer’s score .

# Features

- Random card dealing system

- 👤 Player vs 🤖 Computer gameplay

- ♠️ Real Blackjack rules:

   - Ace = 1 or 11

  -  Face cards = 10

  -  Automatic score calculation

  - Blackjack detection (21 with 2 cards)

  - Replay the game multiple times

# Technologies Used

- Python

  - Random module

  - Functions and loops

  - Conditional statements

# How It Works

- The player and computer are each dealt two cards

- The player can:

  - Type 'y' → draw another card (hit)

  - Type 'n' → stop (stand)

- The computer automatically draws cards until it reaches 17 or higher

- Final scores are compared

- The winner is displayed

**Example:**
````
Your cards: [10, 7], current score: 17
Computer's first card: 9

Type 'y' to get another card, type 'n' to pass: n

Your final hand: [10, 7], final score: 17
Computer's final hand: [9, 8], final score: 17

It's a Draw 🙃
````
